    🔑 Kunci Jawaban
    • Aktivitas 1: pernyataan 1 sampai 6 benar. Dua pernyataan pengecoh (lahir 1900; jadi bersekolah ke Belanda) salah.
    • Urutan proses: penulis menulis ide; kirim ke penerbit dan dibaca editor; rapat redaksi; catatan editor dan revisi; korektor bahasa; pengarah visual dan ilustrator; desainer menata halaman; cetak; pemasaran.
    • Majas: keras hati; pipi ranum tomat; jendela dunia; naik darah.
    • Teks ikan mangrove: ikan pengunjung masuk saat air pasang; ikan sembilang adalah penetap sementara.

    🌐 Cara Mengunggah ke GitHub Pages
    1. Buat repositori baru di GitHub (publik).
    2. Unggah file index.html ini ke repositori.
    3. Buka Settings → Pages, pilih Branch main dan folder / (root), lalu Save.
    4. Tunggu 1 sampai 2 menit. Tautan akan muncul di halaman yang sama. Buat QR code dari tautan itu untuk dibagikan ke siswa.

    Catatan: ilustrasi memakai emoji. Jangan menyalin gambar komik atau ilustrasi dari buku teks tanpa izin; buat sendiri atau gunakan aset berlisensi bebas.
